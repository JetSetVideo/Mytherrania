GENERATED by `deno run -A tools/capture-wave-tex.ts doc` from `artifacts/wave-tex/captures/*/index.json`. Do not edit by hand.

## How a run is made

- `tools/capture-wave-tex.ts capture --run <id> [--src head] [--quick|--full] [--diff <prev>]` bundles a QA page (BUILD_OUT=dist-capture, port 8873) that builds each
  subject with `PreviewScene.buildPreviewRig` (the Creator's call), removes the weapon, and renders tiles of 420x560 px with a 24 deg
  perspective camera at a fixed distance per framing target (whole body / face / left forearm / upper back, from the rig's own bones).
- Each tile carries the HUD band (src/graphics/CaptureHud.ts, 10 px Menlo) BELOW the render: run, commit (+hash of uncommitted src/ when dirty),
  build time, race/sub-race/sex/class, variant, active layers + operators, marks, channel view, light setup, camera yaw/pitch/distance/fov,
  triangles (rig incl. the removed weapon), rig build ms and frame ms (second draw, `readPixels`-synchronised).
- Lights: `studio` = the Creator's `PreviewStage.draw` (overhead key + face fill + shadow pass); `rim` = camera-relative back key, ambient 0.27;
  `flat` = no key, ambient 1 (the albedo x paint read, cel rim kept); `daylight`/`dusk` = `environmentAt` sun colour/intensity/ambient at 13 h and at
  4 deg elevation, azimuth turned to 35 deg front-left of the subject. Non-studio setups have no cast shadow.
- Subjects: 4 races x 2 sexes (Warrior, no sub-race, base height/weight x race build) x `reference` (marks = none), `marked` (the fixed
  `MARKED_SET`: forearm laceration + band tattoo, back claw scar + tribal tattoo, face incision + dotwork; validated per race with M's
  `validateMarks`, issues printed in the HUD as `!issue`) and `marked-bare` (same marks, garment off so torso/back marks are visible;
  angles + channels only), the marked variants only when the tree has `appearance.marks`. HUD `marks(n req, m decals, k under garment)`:
  m = decals the rig packed (`rig.material.packed.count`), k = marks M's validateMarks calls covered by the outfit (R's skin mask hides them).
  `reference` = an EXPLICIT empty set (R's TEX_DEFAULTS would otherwise draw generated marks). `index.marksEffect` = marked vs reference
  sheets of the same run (what the marks changed on screen; `<sheet>.marks.png`). `--quick` = 4 subjects (human-m, ork-f, elf-f, dwarf-m), 6 angles, lights at 3/4, channels at 3/4 + forearm.
- Channel views (`final albedo roughness height normal ao marks`) only when the tree exports R's `setChannelView`.
- `index.json`: per image {id, path (sheet), rect/render/hudRect in the sheet, race, sex, variant, light, angle, view, camera, regions (face/forearm/back
  boxes in render px), stats (coverage, luma mean/p5/p50/p95 of subject pixels), hud text per field, vsPrev}.
- Diff: render rects only (HUD bands always differ), pixel changed when mean |dRGB| > 16 (0..255); changed-region boxes = 16 px grid cells with
  >= 4 changed px, 8-connected (`CaptureHud.diffImages`). Diff PNG: the new run in grey, changed pixels red, boxes yellow.

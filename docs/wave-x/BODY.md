# Wave X — lane B: body + viewer

All numbers below are generated by code from `artifacts/qa-wave-x/body/measure.json` (tools/measure-wave-x-body.ts),
`report-after.json` / `report-before.json` (tools/probe-wave-x-body.ts, real Chrome) and `belly-frequency.json`.
Reference bodies: seed 7 Warriors — human 1.70 m/72 kg, wood elf 1.77/60, mountain dwarf 1.39/70, ironhide ork 1.95/120.

## What changed

- **Viewer** (`src/graphics/PreviewScene.ts`): a stone pedestal (`PEDESTAL_RADIUS` = 0.6 m, a 0.12 m plinth on a wider
  footing, two chiselled rings, forged-iron bands) replaces the dark disc. The camera distance is
  `previewFraming(...)`: frame top = 4.2·R, frame bottom = −(plinth + 0.15·R), distance = half span / tan(fov/2),
  floored so the base fits a narrow canvas — **a function of R and the fov, not of the model's height**. Clip rule: only
  a model whose measured top is above 4.2·R (2.52 m) is framed by its own height (`framing().clipped`). Every default
  race roll fits under it. Key light from straight above, slightly front (elevation 78°), fill lowered; a
  back-face depth pass from that key into a 1024² RGBA-packed shadow map, received by body and pedestal through the
  shared cel uniforms, which the preview sets for its own draw and restores right after. A painted contact blob (0.7,
  σ 0.3 m) sits under the feet. Public API unchanged; added QA-only methods (`pedestal()`, `debugShadowProbe()`,
  `debugLighting()`, `debugDetail()`, `debugCamera()`, `debugRenderMs()`, `profile` getter, the
  `globalThis.__MYTHERRANIA_PREVIEW__` hook). No DOM. `previewKey` now includes sex and age, and the Creator's
  body spec carries the **sex** (it was dropped, so the Creator always showed the male body).
- **Physique** (`src/graphics/body/Physique.ts`, wired in `Anatomy.buildPlan`): a sculpt of the **rendered skin tree only**
  (`plan.skinRoot`), after the symmetry pass. Physics reads `plan.root`, which is byte-identical with and without the
  sculpt (SPEC X57), so no ragdoll, hitbox, abduction solve or planted-foot number can move. The skin gets: deltoid caps
  over the clavicle line plus a valley cutter, two rectus sheets plus a linea alba groove, girth slimming (rib, waist,
  obliques, pelvis, glutes, thighs, shins, biceps/triceps — not the shoulder girdle, pecs, forearms, hands or feet),
  a flat default belly (no deeper than 0.86 × the chest's half-depth), the rare fat belly, and the male crotch bulge.
  The skin's polygonising box grows by whole cells where the sculpt stands proud (`skinBounds`), so the physics
  box and the grid phase stay put.
- **Rare fat belly** (`src/game/BodyProfile.ts`): `FAT_BELLY_CHANCE` dwarf 12 %, ork 7 %, human 4 %, elf 0;
  `rollFatBelly(rng, race)` (always two draws), `fatBellyFor(seed, race)` on its own salted stream, so
  `randomSilhouette` and the asymmetry draws are unchanged. `BodySpec.belly` can override it. A fat belly hides the six-pack.
- **Surface detail** (`src/graphics/shaders/CelSkinned.ts`, opt-in `detail`): a procedural height field on the
  bind-pose position, turned into a bump normal with screen-space derivatives. Its lambert change also goes into the
  albedo, because under cel bands a bump alone only moves a band edge. It draws the six-pack (four segments, slightly
  offset intersections, dome bellies), skin grain (~1.1 cm and ~3.8 mm), sparse pores (~1.7 mm), slow mottling, and a
  twill plus slubs on the garment. Each octave fades out as its period nears a pixel. `SkinnedHumanoid` adds an
  `aSurface` attribute (garment/trunk) and writes each rig's abs band.

## Honest gaps

- **Render-only means the combat capsules are fitted to the pre-wave body.** The visible waist is 10–14 % smaller
  than the body the hitboxes were fitted to, so a blade can register a hit up to roughly (before − after waist)/2π
  outside the visible skin at the waist (≈ 18 mm human, ≈ 36 mm ork). Hits were never pixel-exact (capsules), but the
  gap grew. Moving the physics with the skin is the pre-wave failure mode (ragdoll/planted-foot pins), so it was not tried.
- **The six-pack geometry is weak at grid resolution.** The linea depth on the built mesh is only 0–5 mm
  (cells are 22–35 mm), so the visible six-pack comes from the shader. Vision QA still calls it "grid-like" at a distance.
- **Pores are sub-pixel in the default framing.** About 6 mm per pixel at DPR 1, so the pore and twill octaves fade out
  on purpose. They show only in close-ups and on DPR-2 screens.
- **Overhead key versus faces.** With the light 78° up and a low fill, faces and the belly sit in the shade band. That
  is what was asked for, but vision QA flagged faces as hard to read.
- The arena still renders female fighters as male bodies, because Engine's spec omits `sex` (lane L's file).
  Reported in `artifacts/messages-wave-x-B.md`. The male bulge therefore also shows on every arena fighter.
- **Frame cost is measured only in the viewer** (+0.397 ms
  at 636×778, inside noise). The arena's FrameBudget was not re-measured in a live match; the framebudget unit test passes.
- **Before shots are at DPR 1 (319×390) and after shots at DPR 2.** The before run was re-done with the same probe;
  it has no QA hook, so the before set is male only, with no close-ups.
- `spec_test.ts` "SPEC LL3" fails: the creator sheet has 7 primaries now (agility). This comes from the phase-0 agility
  change, not lane B.

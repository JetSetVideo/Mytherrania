# Wave Z — derived statistics (lane S, contract C-SHEET)

`derivedSheet(profile)` (src/game/DerivedSheet.ts) returns `{ attributes, derived }`; `statSheetHtml(sheet, { compact })`
(src/ui/StatSheet.ts) renders it. Every value is ONE call into the game's own functions on the stat block the duel runs.

## The pipeline (what the duel runs)

`fightStats(profile) = applyLevel(applyProfileTweaks(applySecondary(applyRaceBonus(createStats(class), race, sub, sign), sub, sign), profile), level)`
— Engine.#startFight's order: `createFighter` (race bonus, secondary bridge) -> `#applyTweaks` -> `applyLevel` (+3 %/level on
health and power). `applyProfileTweaks` is a copy of the private `Engine.#applyTweaks`, text-pinned by SPEC Z25.
No gear tier (the live game has none; batch matches only). `CreatorRoll.rolledStats/tweakedStats` now delegate to it.

## The references (one per section)

| section | value | delta (the "+/-") |
|---|---|---|
| attributes | sheet-scale attribute = Leveling class sheet + modifier (equals `profile.allocated` when no birthsign/crit) | `fightStats()[attr] − createStats(class)[attr]`: what race, sub-race, birthsign, the secondary crit bridge (reflex, 12.5/crit) and the hand-tweak add to the CLASS baseline |
| derived | the game function's output | `value − field mean`: the mean of the SAME function over the 32 class x race reference fighters (no sub-race, no sign, level 1, no tweak, class weapon) |

Tone: `data-tone = delta`, `data-tone-span` = 4 attribute points, or 2 standard deviations of the row over the reference
fighters; `data-tone-invert="1"` where lower is better (intervals, cast time, damage/crit/wounds taken, cooldown).

"Even foe" (Hit, Crit chance, Hit taken, Crit taken) = the field-average fighter: the mean `fightStats` block of the 32
reference fighters, ONE fixed opponent so the row moves with your numbers only. Hit = `attackDamage(you, foe, 0.5, 0.5)`:
mid-roll, non-crit (critRoll 0.5 is above the 15 % crit cap), the classic damage path.

## Honest limits

- **Derived deltas include level growth**: the references are level-1 fighters, so a level-12 hero's health and power
  read well above the field (applyLevel: +3 %/level) — intended: the (+/-) is the hero against the neutral fighter.
- **Graze is not a chance**: agility's dodge is a deterministic divisor on every blow taken (`Agility.dodgeDivisor`), shown
  as the share of each blow it takes off, `1 − 1/divisor` (negative for a heavy/clumsy body).

- **No health regeneration row**: the game has none (only the Wave Y health potential recovers after rest).
- **No per-fighter power mana cost**: the engine pays the flat `PowerCost.SKILL_RESOURCE_COST` (power 24 mana / 8 stamina).
- **Technique cooldown is class-level**: `Skills` derive cooldowns from the class preset, so race/tweaks cannot move it.
- **Crit chance sits on its 15 % cap** for almost every fighter vs the even foe (`criticalChance` caps at 0.15): real, flat.
- **Weapon rows** (Swing interval, Attacks, Reach) use the weapon forged from the profile's NAME seed (`createFighter`'s
  default seed). A live match re-forges a chosen weapon from the match seed, so those move a few per cent between matches;
  "random" weapons are re-rolled each match. No `weaponType` = the classic class weapon (tempo 1).
- **Two attribute scales**: attributes show the sheet scale (~6-17); `Effective agility` is `Agility.effectiveAgility`
  (runtime + SHEET_OFFSET 6 − mass drag), so it can differ from the Agility row by a point (class sheet − runtime is 5..7).
- **Engine clamp finding (reported to PARENT, board Z-9)**: `#applyTweaks` clamps attack power to 14·DAMAGE_SCALE after the
  secondary bridge lifted it, so a +2 STR tweak can LOWER power (seed mulberry32(11): 728 -> 700). The sheet shows the truth;
  tests/wave_x_ui_test.ts X38 was updated to accept the ceiling, with that reason.
